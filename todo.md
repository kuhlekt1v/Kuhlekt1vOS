    ```
    NAME
        man - Show system reference manuals

    SYNOPSIS
        man [options] page
        man -k [options] regexp

    DESCRIPTION
        Each page arguments given to man is normally the name of a command.
        The manual page associated with this command is then found and displayed.

    OPTIONS
        -k Search for manual page using regexp
    ```
